Workstream gives each task its own cloud desktop with an AI agent working on it. You write what you want done, a Linux desktop starts for that task, and the agent does the work there. You watch the screen in your browser, write to the agent beside it, and use the mouse and keyboard yourself when you want to.

These pages say how each part works and what the numbers are.

## Pages

- [How Workstream works](/docs/how-it-works): a task, its desktop and its agent, and how you watch, write and take over.
- [Desktops](/docs/desktops): what is installed on a desktop, the three sizes, and how long a start takes.
- [AI on a desktop](/docs/ai): the Workstream agent and OpenCode, ready with no sign-in, and how their calls are counted.
- [Running, paused, archived, deleted](/docs/running-paused-archived): what happens to a desktop nobody is using, and what is kept.
- [Environments](/docs/environments): the repository, setup script, variables, apps and size a task starts with.
- [GitHub](/docs/github): signing in with GitHub, and how a desktop pushes branches and opens pull requests as you.
- [Sharing](/docs/sharing): giving one task to someone outside the team, to watch, write or use the desktop.
- [Usage and limits](/docs/usage-and-limits): the model allowance, who and what used it, desktop time, storage and how many desktops run at once.
- [The command line](/docs/command-line): starting and following tasks from a terminal.
- [Security](/docs/security): what a desktop can reach, who can see its screen, and where things are kept.

## Words these pages use

| Word | Meaning |
| --- | --- |
| Task | One piece of work. It has a desktop and a conversation with the agent on that desktop. |
| Desktop | The task's cloud computer: a Linux virtual machine with a graphical desktop. |
| Agent | The program on the desktop that does the work. |
| Environment | What a desktop starts with: its apps, its size and, optionally, a repository, a setup script, variables and instructions for the agent. |
| Team | A group of people who share tasks and environments. |
