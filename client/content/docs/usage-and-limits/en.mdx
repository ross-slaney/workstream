Usage is counted per team. Everyone on the team can see it on the Usage page. Workstream has no prices and takes no payment yet, so these are limits, not a bill.

| What | How it is counted | The limit |
| --- | --- | --- |
| Models | The cost of every model call from the team's desktops, in dollars | An allowance per team per calendar month |
| Desktop time | Hours a desktop is running, counted separately for each size | None of its own; the limit is on how many run at once |
| Storage | The disks of paused desktops, archived desktops and saved setups | None today |
| iPhone builds | Minutes a Mac spends building the team's iPhone apps | 30 builds asked for in a day |
| Desktops at once | Desktops running at the same moment | A number per team |

## Models

Every model call from a desktop goes through Workstream: the agent's, and those of a tool you run on the desktop yourself, such as [OpenCode](/docs/ai#opencode). Workstream counts the call's tokens and charges their cost in dollars against the team's allowance for the calendar month. The Usage page shows how much of the allowance is used and how much is left.

Under that, the page shows who and what used the models this month:

- **Day by day**: what each day cost.
- **People**: each person's tasks, desktop time, calls and cost. A desktop's calls count to the person who started the task.
- **Tools**: the Workstream agent, OpenCode, and any other tool that called the models.
- **Models**: how much was sent to each model and how much it answered.
- **Tasks**: the ten tasks that cost most.

A team administrator sees everyone's. Anyone else sees their own use, and the team's total. Workstream keeps each call's size and cost and never what was sent or answered.

When the allowance is used up, the agent and the tools stop until the next month starts or the allowance is raised. Desktops keep running and you can still use them yourself. There is no bring-your-own-key: a team cannot use a model key of its own.

## Desktop time

A desktop adds time from when it starts until it is paused. Time is counted separately for Small, Standard and Large desktops, because a larger desktop costs more to run. A paused or archived desktop adds none.

## Storage

Three kinds of storage are counted, in GB-months:

- the disk of each desktop, while it is running or paused,
- the snapshot of each archived desktop,
- each environment's saved setup.

The Usage page shows how much the team has of each. To use less, delete tasks you no longer need. See [Running, paused, archived, deleted](/docs/running-paused-archived).

## iPhone builds

An iPhone app is built on a Mac, which a desktop asks for when the app's native code has changed. The time the Mac spends is counted in minutes, whether or not the build worked. A team that has had no app built does not see this on its Usage page.

A team can ask for 30 builds in a day. A desktop that asks for another is told the limit is reached, and can still take any app the team already has.

## Desktops at once

A team has a limit on how many desktops run at the same moment. Starting a task or resuming a paused one is refused when the team is at its limit, with a message that says so. Pause or delete a task to make room. Paused and archived desktops do not count.

## Changing a limit

The model allowance and the limit on running desktops are set per team by Workstream. A team cannot change them itself.
